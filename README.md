## 🚀 Deploy to GitHub Pages

1. **Fork or clone** this repository
2. Go to your repo → **Settings** → **Pages**
3. Under *Source*, select **Deploy from a branch**
4. Choose **`main`** branch → **`/ (root)`** folder
5. Click **Save** — your site will be live in ~60 seconds at:

```
https://<your-username>.github.io/<repo-name>
```

## 🎨 Customisation

To make this your own, edit `index.html` and update:

```
Name, title, summary          → Hero section & About section
Contact details               → About card & Contact section
Work experience               → Experience timeline
Education                     → Education cards
Skills & proficiency levels   → Skills grid (data-width values, 0–100)
Projects & certifications     → Projects & Certifications sections
Profile photo                 → Replace the base64 image src in the hero
```

**Colour palette** (CSS variables at top of `<style>`):

```css
--navy:      #0B1F3A   /* Dark backgrounds */
--gold:      #C9A243   /* Accent colour    */
--gold-light:#e8c46b   /* Hover states     */
--off-white: #F4F7FC   /* Alt sections     */
```
